### 🔹 Notion Full-Stack Explorer  
**(3rd Project | Built From Scratch)**

A full-stack web application that brings your entire **Notion workspace into one organized, secure dashboard**.

#### 💡 Why I Built It
Managing multiple Notion pages became risky due to bugs that could potentially wipe months of work.  
I needed a **personal backup & organization system** — so I built one.

#### ✨ Highlights
- 🎨 Clean, responsive UI with step-by-step onboarding  
- 🔄 Real-time updates without page refresh  

#### ⚡ Performance
- **First Contentful Paint:** 1.2s  
- **API Response Time:** <150ms  
- **Bundle Size:** <450KB  

#### 🔐 Security
- Token encryption in transit  
- Multi-tenant architecture  
- No persistent token storage  
- CORS-protected endpoints  

#### 🧰 Tech Stack
`React 19 • TypeScript • Node.js • Express • Notion API`

#### ✅ Results
- 50+ files managed effortlessly  
- Comments visible at a glance  
- Mobile-first responsive design  
- Open-source & free to use  

🌐 Live Demo: https://notion-fullstack-app.vercel.app
